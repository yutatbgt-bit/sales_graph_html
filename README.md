# 売上推移可視化ダッシュボード (Sales Graph Dashboard)

Excel形式（`.xlsx`, `.xls`）の販売管理データを取り込み、日別の**売上高・来客数・客単価**を自動集計して3軸複合グラフおよび詳細対比表を瞬時に生成する、高機能・高セキュリティなブラウザ完結型Webアプリケーションです。

---

## 🌟 主な特徴・機能

### 1. 直感的なデータ取り込み（Excel対応）
- **ドラッグ＆ドロップ対応**: 「基準データ（昨年売上）」と「比較日データ（今期売上）」のExcelファイルをドロップまたはクリック選択するだけで即座に自動解析します。
- **柔軟なフォーマット解析**: 店舗・期間メタデータ、日別集計行（売上・客数・客単価）を自動識別します。

### 2. 多角的なビジュアル分析（3軸複合グラフ）
- **3軸ハイブリッドチャート (Chart.js)**:
  - 売上高（棒グラフ / 第1軸: 円）
  - 来客数（折れ線グラフ / 第2軸: 人）
  - 平均客単価（折れ線グラフ / 第3軸: 円）
- **対比方式のワンクリック切り替え**:
  - **同日対比**: カレンダー上の同日（例: 9/1 vs 9/1）で実績を比較
  - **同曜日対比**: 同じ曜日同士（例: 第1火曜日 vs 第1火曜日）で実績を比較

### 3. エグゼクティブKPIサマリーカード
- 合計売上高（前年比増減・達成率）
- 総来客数
- 平均客単価
- 営業日数 / 1日あたり平均売上

### 4. 日別詳細データ一覧テーブル
- 日別実績の詳細テーブルを展開表示可能
- 売上・客数・客単価の前年比（%）を自動計算

### 5. レポート出力 & ユーティリティ
- **高解像度PNG保存**: 表示中のグラフをレポート・社内資料向けにワンクリックで画像エクスポート
- **ダークモード / ライトモード対応**: ワンクリックでテーマを切り替え可能
- **ワンクリックリセット**: 読み込みデータを即座に初期化

### 6. 堅牢なセキュリティ・完全ローカル完結
- **完全オフライン動作**: 依存ライブラリ（Chart.js, SheetJS）はすべてローカルバンドルされており、機密データ（売上情報等）が外部サーバーへ送信されることは一切ありません。
- **厳格なContent Security Policy (CSP)**: インラインスクリプトや外部への不正リクエストを遮断
- **XSS防御**: すべてのDOM描画においてサニタイズおよび安全なDOM APIを使用

## 🚀 使い方

1. 本リポジトリをクローンまたはダウンロードします。
2. `sales graph.html` をお好みのモダンブラウザ（Google Chrome, Microsoft Edge など）で開きます。
   - ※ Webサーバーを介さず、ローカルファイルを直接ダブルクリックして起動できます。
3. 画面右上のアップロードエリアからExcelファイルを選択します:
   - **基準データアップロード**: 昨年の売上データ
   - **比較日データアップロード**: 今期の売上データ
4. グラフやKPIカードが自動更新されます。「同日対比」「同曜日対比」の切り替えや「データ一覧を表示」をクリックして詳細をご確認ください。
5. 「グラフをPNG保存」ボタンを押すことで、表示中のグラフ画像をダウンロードできます。
